Exercices Bash

Ce dépôt regroupe mes premiers exercices de scripting Bash, réalisés dans le cadre de mon apprentissage de Linux.

Scripts

logsupp.sh — Suppression de fichiers journaux

Ce script permet de rechercher les fichiers .log dans un répertoire indiqué par l’utilisateur.

Il vérifie l’existence du répertoire, affiche les fichiers trouvés et demande une confirmation avant leur suppression.

Notions travaillées :

* Variables et saisie utilisateur avec read
* Vérification de l’existence d’un répertoire
* Conditions if, else
* Recherche et manipulation de fichiers
* Confirmation avant une opération de suppression

testdeux.sh — Script interactif

Ce script demande à l’utilisateur son nom et son humeur, puis affiche différentes réponses selon les informations saisies.

Notions travaillées :

* Saisie utilisateur avec read
* Affichage avec echo
* Temporisation avec sleep
* Conditions if, elif, else
* Comparaison de chaînes de caractères

Objectif du dépôt

Ces exercices m’ont permis de découvrir les bases du scripting Bash et de me familiariser avec l’automatisation de tâches simples sous Linux.
